# Contributing

Thank you for helping. EvolAI is at specification stage; read [docs/PRD.md](docs/PRD.md) and the
[architecture decisions](docs/adr/) first.

- Open an issue before large changes; small fixes can go straight to a pull request.
- One topic per pull request, with tests and an updated doc when behaviour changes.
- Never include real client data, personal data, credentials or host names: fixtures must be synthetic.
- Security issues: do not open a public issue, see [SECURITY.md](SECURITY.md).
- By contributing you agree your contribution is licensed under the repository license (Apache-2.0).
