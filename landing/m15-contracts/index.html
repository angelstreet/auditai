What is this?

@auditai/contracts is the public surface of the project: 14 entity modules, 120+ tests, branded UUIDs, discriminated audit-log variants, status-transition schemas, privacy-by-construction respondent payloads. The @auditai/domain, @auditai/ai, @auditai/web, and @auditai/ui packages all import from this single source so validation logic never diverges.

Cross-cutting guarantees

  • Branded UUIDs \u2014 TenantId \u2260 UserId at the type level.
  • Discriminated audit logs \u2014 targetKind='opportunity' refines targetId to OpportunityId.
  • Status transitions are schemas \u2014 opportunityStatusTransitionSchema + synergyStatusTransitionSchema encode the graph; the data layer runs the parse.
  • Privacy by construction \u2014 the respondent-facing surfaces never carry quiz_score; the analyst reads the row directly.

Tier mascots (M14)
